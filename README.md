# VideoCat 视频压缩猫

> 别研究码率了，告诉猫你想要多大。

**喵造实验室 011**。一个 local-first 的 Windows 视频压缩工具。

## v0.1

核心场景：

> “我不懂 CRF / bitrate，我只知道这个视频要压到 25MB 左右。”

VideoCat 会根据视频时长和目标文件大小自动计算码率，并使用 FFmpeg H.264 两遍压缩，尽量接近用户输入的目标体积。

### 功能

- MP4 / MOV / MKV / AVI / WEBM 等常见视频输入
- 统一输出 MP4（H.264 + AAC）
- 常用目标大小：10 / 20 / 25 / 50 / 100 MB
- 自定义目标大小
- 保持原分辨率
- 最长边限制：1920 / 1280 / 854
- 96 / 128 / 160 / 192 kbps 音频
- 批量视频
- 两遍压缩
- 压缩前显示预计视频码率与清晰度提示
- 原视频不覆盖
- 同名文件自动避让
- 默认输出到 `VideoCat_压缩结果`
- 全程本地处理，不上传视频

## 关于“目标大小”

最终文件体积会受到容器开销、音频轨、视频复杂度等影响，因此 **VideoCat 的目标大小是尽量逼近，不承诺字节级精确**。

为了降低超出目标的概率，v0.1 在计算可用总码率时预留约 3% 的容器开销。

## 隐私

视频不会上传到 VideoCat 服务器。FFmpeg 在本机执行压缩。
